# Conjugaison

Exercices de conjugaison pour Daniel (11VG), en français, pensés pour le téléphone.

- 16 verbes : dire, pouvoir, aller, recevoir, apercevoir, peser, lever, élever, couvrir, ouvrir, offrir, souffrir, boire, lire, assiéger, mouvoir.
- Tous les temps de l'indicatif, subjonctif présent et passé, conditionnel présent et passé (2e forme en option), impératif présent et passé, gérondif présent et passé, participe présent et passé.
- 4 exercices : 20 questions tirées au hasard, phrases à trous avec concordance, actif et passif, temps simple vers temps composé. Plus un test mélangé noté.
- 143 phrases dans `src/content/`. Les formes sont calculées par `src/engine/verbs.js` et `npm test` vérifie chaque phrase contre le moteur.

```
npm install
npm run dev
npm test
```
